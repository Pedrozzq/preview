# Zoo Tabacaria — protótipo de site

Projeto front-end responsivo para a Zoo Tabacaria, com:

- catálogo de acessórios e conveniência;
- filtros por categoria;
- carrinho persistente em LocalStorage;
- cadastro de endereço;
- preenchimento de CEP via ViaCEP;
- resumo de checkout;
- geração de mensagem do pedido;
- aviso 18+;
- comunicação de entrega em Ouro Preto até 01:00.

## Rodar
Abra `index.html` no navegador. Para testar melhor o preenchimento de CEP, use um servidor local (por exemplo, Live Server no VS Code).

## Para colocar em produção
1. Conectar clientes, endereços, estoque e pedidos a um backend.
2. Adicionar autenticação/validação e política de privacidade/LGPD.
3. Configurar taxa de entrega por bairro/raio.
4. Integrar pagamento (Pix/cartão) apenas para itens permitidos.
5. Configurar WhatsApp comercial, se desejado.
6. Revisar a operação com contador/advogado e Vigilância Sanitária local.

## Observação regulatória
Este protótipo não inclui produtos fumígenos derivados do tabaco no checkout. A oferta e venda desses produtos pela internet é vedada no Brasil segundo a regulamentação sanitária citada na conversa.
